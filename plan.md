# NavbatPro rejasi

NavbatPro kichik klinika va xizmat markazlarida telefon yoki chat orqali navbat kelish muammosini kamaytiradi. Mijoz xizmat, mutaxassis va bo‘sh vaqtni tanlaydi; backend slotni qayta tekshiradi va bronni doimiy saqlaydi.

Stack: Node.js HTTP server, REST API, responsive HTML/CSS/JavaScript va JSON database. Keyingi production bosqichida PostgreSQL, SMS reminder, login va kalendar integratsiyasi qo‘shiladi.

Dizayn: sokin tibbiy interfeys — oq fon, ko‘k-yashil primary rang, aniq vaqt kartalari va ishonch beruvchi status chiplar. Desktopda xizmatlar chapda, vaqtlar o‘ngda; mobil ekranda bitta oqim.
